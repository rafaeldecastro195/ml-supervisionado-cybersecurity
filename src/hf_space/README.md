# Deteccao de Ameacas Ciberneticas com ML

Interface Streamlit para classificacao de conexoes de rede como **Normal** ou **Ataque**
usando o modelo Stacking Ensemble (MLP 3 camadas) treinado no dataset UNSW-NB15.

**Acuracia:** 89,73% | **Threshold F1-otimizado:** 0,7453
